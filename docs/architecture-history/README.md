# Architektur-Historie

Belegmaterial zum Gegenreview der Evolutionsarchitektur V1 → V2. **Keine dieser
Dateien gilt.** Verbindlich ist ausschließlich `docs/Evolutionsarchitektur V1 zu
V2.md` im Ledgerstand C-001–C-082.

Der Review lief in elf Runden zwischen dem 24. und 26. Juli 2026: Codex
editierte das Dokument, Claude prüfte gegen, jeder Einwand bekam eine C-ID mit
Passage, Urteil, Evidenz, Gate, Datenquelle, Abnahmekriterium und Rollback. Jede
Runde entstand als eigene Datei, damit die Vorgängerfassung unverändert
nachprüfbar blieb. Abschnitt 28 der geltenden Fassung trägt die vollständige
Kette samt Korrekturverweisen — diese Dateien braucht man nur, wenn man den
Wortlaut einer Zwischenfassung nachlesen will.
